# Проверка входа по кнопке под сотрудником

Узнаем, может ли сотрудник без прав администратора подключить amo одной кнопкой. По справке amoCRM интеграции
ставит только администратор, но вживую это не проверено. От ответа зависит, что справка amo советует сотрудникам.

**Результат 24.11.2026:** amoCRM не даёт сотруднику подключиться. Под кнопкой «Разрешить» она пишет: «Интеграция не
может быть установлена в выбранный аккаунт. Первичная установка интеграции доступна только администраторам
аккаунта.» Повторять тест стоит, если amoCRM поменяет это правило.

Понадобится тестовый аккаунт fashionscrew и почта, к которой есть доступ. Займёт минут десять.

## 1. Добавить сотрудника

Под администратором, в обычном окне браузера:

1. Откройте <https://fashionscrew.amocrm.ru>.
2. Слева **Настройки** → **Пользователи**.
3. Нажмите **Добавить пользователя**.
4. Заполните имя и почту. Подойдёт ваш адрес Gmail с плюсом перед `@`, например `имя+amo`: письма придут в обычный ящик.
5. В выборе группы укажите **«Бесплатные пользователи»**. Такой пользователь не администратор и не занимает
   платное место. Если amoCRM просит докупить место, остановитесь.
6. Сохраните.
7. Откройте почту. Придёт письмо от amoCRM со ссылкой или с данными для входа. Если там ссылка, задайте по ней
   пароль.

Справка amoCRM: [бесплатные пользователи](https://www.amocrm.ru/support/free_user/create_free_users/),
[добавление пользователя](https://www.amocrm.ru/support/user/create_users/).

## 2. Войти под сотрудником

1. Закройте все приватные окна Firefox, если они открыты. Иначе новое приватное окно возьмёт вход оттуда.
2. В терминале выполните одну команду:

   ```sh
   ruby /home/leemour/Projects/AI/amo-cli/bin/one-click-live https://fashionscrew.amocrm.ru
   ```

3. Откроется **приватное окно** Firefox со страницей WireCat. Нажмите синюю кнопку.
4. amoCRM спросит логин и пароль. Войдите **под сотрудником**, не под администратором.
5. Дальше amoCRM покажет одно из двух:
   - окно «WireCat получит доступ»: в списке «Выберите аккаунт» выберите **fashionscrew** и нажмите **Разрешить**.
     В списке все аккаунты, где есть этот вход. Если в нём есть другие аккаунты, кроме fashionscrew, вход идёт не
     под новым сотрудником: тот состоит только в fashionscrew;
   - отказ: сделайте снимок экрана.
6. Если окно вернулось на страницу WireCat, терминал продолжит сам. Если терминал ждёт, скопируйте адрес из окна и
   вставьте в терминал.

## 3. Что прислать

Весь вывод терминала. В строке `user` видно, кто вошёл:

- `"admin":false` и имя сотрудника: сотрудник может подключиться сам;
- `"admin":true`: вход опять прошёл под администратором, начните с шага 2.1;
- `access was allowed in …, not in fashionscrew.amocrm.ru`: в окне amoCRM выбран другой аккаунт. Удалите в нём
  интеграцию «WireCat» и начните с шага 2.1;
- отказ amoCRM: снимок экрана. Это тоже ответ: тогда сотруднику ключ делает администратор.

## 4. Убрать за собой

- Каждое нажатие кнопки оставляет в аккаунте интеграцию «WireCat». Удалите тестовые в настройках интеграций amoCRM.
- Сотрудника можно отключить: **Настройки** → **Пользователи** → имя → снимите **Активность**.
