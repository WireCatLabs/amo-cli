# amo

`amo` reads and changes an amoCRM or Kommo account's CRM from the terminal, from scripts and from AI agents: deals,
pipelines and their stages, contacts, companies, tasks and notes. Your deals and their clients are copied into the
local WireCat store, so lists, the funnel and search work offline, and `changes list` shows what changed for a
morning digest. Every other operation of the amoCRM API v4 is reachable through `api call`, each with its own
permission.

It has the commands every WireCat CLI shares: `doctor`, `commands`, `config`, `skill`, `mcp`, `runs` and `upgrade`.
Start with [installation](installation.md), then [usage](usage.md).
