# amo

`amo` reads and changes an amoCRM or Kommo account's CRM from the terminal, from scripts and from AI agents. It
signs in with a long-lived token (`session`), and `api` lists, shows and calls every operation of the amoCRM API v4,
each with its own permission.

It has the commands every WireCat CLI shares: `doctor`, `commands`, `config`, `skill`, `mcp`, `runs` and `upgrade`.
Start with [installation](installation.md), then [usage](usage.md).
